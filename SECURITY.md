# Security policy

## Report a vulnerability privately

Use [Security → Report a vulnerability](https://github.com/dukagjina/PC-Center/security/advisories/new)
to contact the maintainer through a private GitHub security advisory.

Include the affected PC Center version, Windows version, steps to reproduce and
the impact. Do not include passwords, tokens, private documents or unrelated
personal information.

Report ordinary interface problems and non-security bugs through
[GitHub issues](https://github.com/dukagjina/PC-Center/issues/new/choose).

## Supported release

The latest published release is the supported version. Version 0.14.9 is
distributed as an unsigned Windows installer. Its SHA-256 is published with
the release; a checksum does not replace trusted code signing.
